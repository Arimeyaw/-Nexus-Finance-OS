# Nexus Finance OS

A scalable SaaS platform for African SMEs built with Next.js, NestJS, Prisma, PostgreSQL, and Docker.

## Workspace structure

- `apps/frontend`: Next.js 15 application
- `apps/backend`: NestJS API server

## Quick start

1. Install dependencies: `pnpm install`
2. Start services: `pnpm dev`
3. Visit frontend: `http://localhost:3000`
4. Visit backend swagger: `http://localhost:4000/api`
